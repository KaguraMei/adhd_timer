# ADHD Timer - 时间可视化工具

一个专为 ADHD 患者设计的时间管理和可视化应用，帮助更好地感知和管理时间。

## ✨ 核心功能

### 📊 七个视图模式
- **今日视图** - 24小时进度网格 + 实时时间条
- **本周视图** - 7天进度展示
- **本月视图** - 当月天数进度
- **本年视图** - 12个月进度
- **人生视图** - 人生进度可视化
- **任务视图** - 完整的任务管理系统
- **倒计时视图** - 专注倒计时功能

### 🎯 任务管理
- 添加、编辑、删除任务
- 三级优先级（高/中/低）
- 任务状态跟踪（待办/进行中/已完成）
- 实时统计和完成率
- 本地持久化存储

### 🎨 主题系统
- 明亮主题（默认）
- 暗黑主题
- 自定义主题（可调整颜色、方块大小、圆角）
- 配置自动保存

### 🎬 动画控制
- 全局动画开关
- 禁用动画时自动使用简化组件
- 提升性能和无障碍支持
- 设置持久化保存

### ⏰ 时间可视化
- 实时更新的时间进度条
- 动画数字显示
- 直观的网格进度展示
- 当前时间指示器

## 🚀 快速开始

### 开发模式
```bash
npm install
npm run dev          # Web 开发服务器
npm run tauri:dev    # Tauri 桌面应用
```

### 生产构建
```bash
npm run build        # Web 构建
npm run tauri:build  # 桌面应用构建
```

## 🛠️ 技术栈

- **框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **动画库**: Anime.js v4
- **桌面应用**: Tauri
- **状态管理**: Vue Composables
- **数据持久化**: localStorage

## 📱 响应式设计

- 桌面端：最大宽度 1200px
- 移动端：完全自适应
- 所有组件针对小屏幕优化
