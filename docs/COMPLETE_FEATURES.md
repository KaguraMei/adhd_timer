## 任务系统使用指南

### 添加任务
1. 在任务输入框输入任务标题
2. 选择优先级（低/中/高）
3. 点击"➕ 添加"按钮或按 Enter 键

### 管理任务
- **切换状态**: 点击任务前的圆圈图标
  - 第一次点击：待办 → 进行中
  - 第二次点击：进行中 → 已完成
  - 第三次点击：已完成 → 待办
- **删除任务**: 点击任务右侧的 🗑️ 图标

### 查看统计
顶部统计卡片实时显示：
- 待办任务数量
- 进行中任务数量
- 已完成任务数量
- 完成率百分比

## 数据持久化
