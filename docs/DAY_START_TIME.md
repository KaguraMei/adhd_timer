# 每日开始时间功能

## 功能说明

每日开始时间功能允许用户自定义一天的开始时间点，而不是默认的午夜 00:00。这对于夜猫子或有特殊作息习惯的用户特别有用。

## 功能特性

### 1. 自定义时间设置
- 在设置面板中可以设置每日开始的小时和分钟
- 支持 0-23 小时，0-59 分钟
- 实时预览设置的时间

### 2. 全局显示
- 在时间条（TimeBar）的右下角显示当前设置的每日开始时间
- 格式：`每日开始: HH:MM`

### 3. 影响范围
设置每日开始时间后，会影响以下时间判断：

- **今日视图**：从设置的时间点开始计算新的一天
- **本周视图**：基于调整后的日期判断当前是周几
- **本月视图**：基于调整后的日期判断当前是几号
- **本年视图**：基于调整后的日期判断当前是第几天

### 4. 数据持久化
- 设置自动保存到 localStorage
- 任务数据已经通过 Pinia store 保存到全局存储

## 使用示例

### 场景 1：夜猫子模式
设置每日开始时间为 **22:00**（晚上10点）

- 在 22:01 之后，系统会认为是新的一天
- 在 21:59 之前，系统仍然认为是前一天

### 场景 2：早起模式
设置每日开始时间为 **05:00**（早上5点）

- 在 05:01 之后，系统会认为是新的一天
- 在 04:59 之前，系统仍然认为是前一天

## 技术实现

### 核心文件

1. **src/utils/dateUtils.ts**
   - `getAdjustedDate()`: 根据每日开始时间调整日期
   - `isSameDay()`: 判断是否为同一天
   - `isSameWeek()`: 判断是否为同一周
   - `isSameMonth()`: 判断是否为同一月
   - `isSameYear()`: 判断是否为同一年

2. **src/stores/settings.ts**
   - 添加 `dayStartTime` 配置项
   - 提供 `setDayStartTime()` 方法

3. **src/composables/useTimeCalc.ts**
   - 更新所有时间计算函数以支持自定义每日开始时间

4. **src/components/settings/SettingsDrawer.vue**
   - 添加时间选择器界面

5. **src/components/layout/TimeBar.vue**
   - 在右下角显示每日开始时间

## 配置结构

```typescript
interface Settings {
  // ... 其他配置
  dayStartTime: {
    hour: number;    // 0-23
    minute: number;  // 0-59
  };
}
```

## 默认值

```typescript
dayStartTime: {
  hour: 0,
  minute: 0
}
```

## 注意事项

1. 时间调整只影响日期判断，不影响实际的系统时间
2. 设置会立即生效，无需重启应用
3. 所有视图会自动响应设置变化
4. 任务的创建时间和完成时间使用实际时间戳，不受此设置影响
