# 快速开始

欢迎使用 ADHD Timer！这是一个快速入门指南。

## 🚀 5 分钟了解项目

### 1. 这是什么？
ADHD Timer 是一个专为 ADHD 用户设计的时间管理工具，帮助你更好地感知和管理时间。

### 2. 核心功能
- ⏰ **多视图时间展示**: 今日、本周、本月、本年、倒计时
- 🎨 **主题定制**: 明亮、暗黑、自定义主题
- 🕐 **自定义每日开始时间**: 适应你的作息习惯
- ✅ **任务管理**: 简单高效的任务列表
- 🎭 **动画控制**: 可关闭动画提升性能

### 3. 特色组件
- **可拖动按钮**: 长按拖动设置按钮到任意位置
- **旋转时间选择器**: 像时钟一样拖动设置时间
- **无限滚动选择器**: iOS 风格的时间选择

## 🎯 常见任务

### 任务 1: 设置每日开始时间
1. 点击右上角设置按钮（⚙️）
2. 滚动到"每日开始时间"
3. 拖动表盘或滚动列表设置时间
4. 点击保存

### 任务 2: 移动设置按钮
1. 长按设置按钮（⚙️）超过 0.5 秒
2. 拖动到想要的位置
3. 松开，位置自动保存

### 任务 3: 切换主题
1. 打开设置面板
2. 选择"明亮"、"暗黑"或"自定义"
3. 自定义模式下可以调整所有颜色

### 任务 4: 添加任务
1. 切换到"任务"视图
2. 点击"➕ 添加新任务"
3. 填写任务信息
4. 点击"添加任务"

### 任务 5: 关闭动画
1. 打开设置面板
2. 找到"动画设置"
3. 关闭"启用动画效果"开关

## 💡 使用技巧

### 技巧 1: 夜猫子模式
如果你习惯晚睡晚起，可以设置每日开始时间为晚上 10 点。这样在 10 点之后才算新的一天。

### 技巧 2: 按钮位置
在移动端，可以把设置按钮拖到不挡住内容的位置，比如左下角或右下角。

### 技巧 3: 性能优化
如果设备性能较低，可以关闭动画效果，界面会更流畅。

### 技巧 4: 主题搭配
- 白天使用明亮主题
- 晚上使用暗黑主题
- 或者自定义一个护眼的主题

## 🔧 技术栈

- **前端框架**: Vue 3 + TypeScript
- **状态管理**: Pinia
- **动画库**: Anime.js
- **桌面应用**: Tauri
- **样式**: CSS Variables
